# 지역 랜딩 SEO 설명문 축약

## 목적

지역별 랜딩 페이지 하단과 검색 메타 설명에 쓰이는 문구를 더 자연스럽고 읽기 쉽게 바꾼다. 검색에 필요한 핵심 키워드는 정확한 형태로 유지한다.

## 적용 문구

각 지역 페이지는 다음 형식을 사용한다.

`{지역명} 종합 집수리 | 전체 리모델링부터 누수피해복구공사, 일상배상책임보험수리, 도배·석고보드 교체까지. 클라쓰가 다른 집수리`

예: `서울 종합 집수리 | 전체 리모델링부터 누수피해복구공사, 일상배상책임보험수리, 도배·석고보드 교체까지. 클라쓰가 다른 집수리`

## 범위와 동작

- `src/landingPages.ts`의 지역 공통 설명문 생성 함수만 수정한다.
- 16개 지역 페이지의 기본 설명문과 관리자 저장값 병합 후 설명문에 같은 문구가 적용된다.
- 서비스 랜딩 페이지 문구와 히어로 문구는 변경하지 않는다.

## 검증

- 모든 지역 페이지 설명문에 `누수피해복구공사`, `일상배상책임보험수리`, `도배`, `석고보드 교체`가 정확히 포함되는지 확인한다.
- 서울 예시 문구와 길이를 회귀 테스트로 고정한다.
- 기존 지역 설명문 테스트와 전체 빌드를 실행한다.

## 트레이드오프

공통 문구를 쓰므로 지역별 세부 생활권이나 주택 유형을 설명문에 넣지 않는다. 대신 지역명, 핵심 서비스, 브랜드 메시지를 짧고 일관되게 전달한다.
